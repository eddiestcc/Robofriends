# RoboFriends

A React application that displays a collection of robot profiles and allows users to search and filter through them by name.

## Features
- Displays robot profiles with names, email addresses, and images.
- Search functionality to filter robots dynamically.
- Responsive card-based interface.

## Built With
- React
- JavaScript
- HTML5
- CSS3

## Concepts Practiced
- React components
- Virtual DOM
- Props and state
- Component-based architecture
- Dynamic rendering
- Search and filtering
- Handling user input

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/eddiestcc/Robofriends.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm start
   ```
